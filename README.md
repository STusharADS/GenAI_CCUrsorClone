# AI Agent CLI Tool

This is a small CLI app that uses an OpenRouter API key to run an AI agent from the terminal.

## Setup

```bash
npm install
```

Create a `.env` file in the project root:

```env
OPEN_ROUTER_API_KEY=your_api_key_here
```

## Run

```bash
node src/script.js
```

Then type your instruction in the terminal and let the agent work.

## Notes

- Requires Node.js 18+
- Main file: [src/script.js](src/script.js)
